# lift2latex

**This repository is archived.** The stylesheets moved, with their history, into [lift-api](https://github.com/sylvainloiseau/lift-api), in `src/main/resources/fr/cnrs/lacito/liftapi/export/latex/`.

There they are XSLT 1.0 (they run with the JDK's processor or `xsltproc`), take their settings as parameters, and are used by lift-api's LaTeX and PDF export (`lift-api latex`) and by DictionaryEditor (Tools > Export as LaTeX / PDF). See the "LaTeX export" section of lift-api's README.
